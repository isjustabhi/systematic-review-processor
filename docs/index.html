    How to use (real app)

    1

    Install once

    Clone the repo, install Python packages, add your API key to .env.

    2

    Start the UI

    python3 run_server.py then open http://127.0.0.1:8000

    3

    Upload & run

    Prompt + PDFs → Start → wait (~30–60 min for 20 papers) → Download CSV.

    4

    Human QA

    Review needs_human_review, eligibility, and any *_ERROR.json files.

    Install on your Mac

    git clone https://github.com/isjustabhi/systematic-review-processor.git
cd systematic-review-processor
pip3 install -r requirements.txt
cp .env.example .env
# Edit .env — add ANTHROPIC_API_KEY=sk-ant-...
python3 run_server.py

    CLI alternative: python3 run_review.py (after PDFs are in RAG Pilot Papers/)

    Who is this for?

    • Lab members — upload papers without R or the terminal
    • Data analysts — batch coding aligned to the v4 prompt schema
    • PI / supervisor — CSV output for spot-checks before scaling to hundreds of papers
